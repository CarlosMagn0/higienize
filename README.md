# Higienize

Plataforma web para contratação segura de diaristas em condomínios.

## Estrutura

- `frontend/`: telas HTML, estilos, interações e imagens da interface.
- `backend/`: API REST em Node.js, Express e SQLite.
- `docs/`: documentação da Fase 01 do 6º período.

## Executar o backend

```bash
cd backend
npm install
npm start
```

A API ficará disponível em `http://localhost:3000`. Consulte `backend/README.md` para os endpoints e dados de demonstração.
